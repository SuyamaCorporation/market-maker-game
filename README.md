# Market Maker Game

**Category:** Finance / Game

Play as a market maker for 4 fictional assets (ZORP, FLUX, MEME, SAFE). Post bid/ask quotes, manage inventory, and profit from spreads while avoiding adverse selection by informed trader bots. Three bot archetypes — noise traders, informed traders, and momentum traders — create realistic market dynamics. Track P&L, win rate, and inventory risk in real time.
